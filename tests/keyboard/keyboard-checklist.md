# Keyboard-only navigation checklist
Tick each item while using only Tab, Shift+Tab, Enter, Space, Esc and arrow keys.

- [ ] First Tab stop is a visible "Skip to main content" link
- [ ] Every interactive element is reachable, in a logical order
- [ ] Focus indicator is always visible
- [ ] No keyboard trap (can always Tab away; Esc closes menus/dialogs)
- [ ] Dropdown menus open with Enter/Space/arrows
- [ ] Carousels/tickers can be paused by keyboard
- [ ] Form errors move focus to an error summary
